# Student Management System

یک برنامه‌ی خط فرمانی (CLI) ساده برای مدیریت اطلاعات دانشجویان، نوشته‌شده با پایتون و مفاهیم برنامه‌نویسی شی‌گرا (OOP).

## امکانات

- افزودن دانشجوی جدید
- نمایش لیست دانشجویان
- جستجوی دانشجو بر اساس نام
- ویرایش اطلاعات دانشجو
- حذف دانشجو
- ذخیره و بارگذاری اطلاعات از فایل

## ساختار پروژه

student-management-python/
│
├── main.py # نقطه ورود برنامه و منوی اصلی
├── student.py # کلاس Student (مدل داده)
├── student_manager.py # کلاس StudentManager (منطق مدیریت)
└── .gitignore

## نحوه اجرا

```bash
python main.py
```

## تکنولوژی‌ها

- Python 3
- برنامه‌نویسی شی‌گرا (OOP)
- Input validation با try/except
